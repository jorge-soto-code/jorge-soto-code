# ¡Hola! Soy Jorge Alexander Soto Gómez 👋

Soy técnico en desarrollo de software y estudiante en formación como tecnólogo en Análisis y Desarrollo de Software. Me interesa construir soluciones web claras, funcionales y útiles, mientras sigo fortaleciendo mis conocimientos y creciendo como desarrollador.
Actualmente estoy buscando una oportunidad laboral o de prácticas. Una posición laboral también me permitiría validar las prácticas necesarias para finalizar mi tecnología.

## Sobre mí
- Ya realicé prácticas como técnico dentro de un equipo de trabajo.
- Tengo experiencia desarrollando proyectos web pequeños y académicos.
- Durante mis prácticas trabajé con WordPress y actualicé el sitio web de la institución.
- Me gusta aprender, entender los problemas y convertirlos en soluciones funcionales.
- Estoy abierto a aprender nuevas tecnologías y a aportar con compromiso en un equipo.
